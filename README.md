# ML Assignment Submission

Two independent problem sets, each in its own directory with its own
code, `requirements.txt`, and `README.md` (approach/methodology/findings).

- **[`problem-set-01-xray-cnn/`](./problem-set-01-xray-cnn)** — CNN for
  pediatric chest X-ray pneumonia classification (TensorFlow/Keras).
  **Test results: 89% accuracy, 0.95 ROC-AUC.**
- **[`problem-set-02-bank-marketing-logreg/`](./problem-set-02-bank-marketing-logreg)** —
  Logistic Regression for bank term-deposit subscription prediction
  (scikit-learn). **Test results: 75% accuracy, 0.77 ROC-AUC.**
