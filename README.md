# ML Assignment Submission

Two independent problem sets, each in its own directory with its own
code, `requirements.txt`, and `README.md` (approach/methodology/findings).

- **`problem-set-01-xray-cnn/`** — CNN for pediatric chest X-ray
  pneumonia classification (TensorFlow/Keras).
- **`problem-set-02-bank-marketing-logreg/`** — Logistic Regression for
  bank term-deposit subscription prediction (scikit-learn).

See each subdirectory's own README for setup instructions, methodology,
and findings. Datasets are not committed (see `.gitignore`) — download
them from the links in the assignment and place them in each
directory's `data/` folder as described in that directory's README.
